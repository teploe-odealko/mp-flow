# Как контрибьютить

Спасибо за интерес к MPFlow. Проект пока находится в ранней стадии, поэтому особенно ценны воспроизводимые баг-репорты, небольшие PR и проверяемые сценарии учета.

## Локальная разработка

Быстрый старт без БД и авторизации:

```bash
npm install
npm run dev          # откройте http://127.0.0.1:5174
```

Полный стек с PostgreSQL и авторизацией, режимы запуска, подтверждение email и тесты — в разделах «Быстрый старт» и «Команды» в [README.md](README.md).

Перед PR запустите:

```bash
npm test
npm run build
```

Если меняли UI, дополнительно проверьте затронутый сценарий в браузере и приложите скриншот или короткое описание проверки.

## Правила PR

- Один PR — одна понятная задача.
- Не коммитьте `.env`, дампы баз, токены, скриншоты с секретами и локальные временные файлы.
- Для учетной логики добавляйте тест на бизнес-сценарий, а не только на отдельную функцию.
- Для API-изменений обновляйте документацию или тесты контрактов.
- Для миграций/изменений хранения данных описывайте обратимость и риск для production.

## Стиль

- Код и документация проекта пишутся на русском, если нет причины использовать английский API-термин.
- UI-тексты должны быть честными и пользовательскими, без внутренних технических пояснений.
- Секреты маркетплейсов и auth-токены не должны возвращаться на frontend и попадать в логи.
