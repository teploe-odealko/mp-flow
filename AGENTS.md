# MPFlow

Все общение, документация и артефакты проекта — на русском, если пользователь явно не попросил иначе.

## Рабочий контур

Проект находится в корне репозитория. Пользовательский бренд — MPFlow.

## Общие правила

- Доделывай просьбы до конца и проверяй результат.
- Если меняешь веб-сервис, проверяй сценарий через браузер или computer use.
- Не коммить `.env`, дампы баз, токены, локальные tmp-файлы и скриншоты с секретами.

## Frontend

- Не добавляй лишние плашки с внутренним контекстом разработки.
- UI должен вести пользователя по одному понятному сценарию, без дублирующих развилок.
- Тексты должны описывать реальное поведение системы, а не желаемое будущее.
